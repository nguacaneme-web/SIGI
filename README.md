# SIGI - Sistema de Gestión de Incidentes

Aplicación web desarrollada en Python y Flask para el registro,
consulta, actualización y eliminación de incidentes de seguridad.

## Tecnologías

- Python
- Flask
- SQLite
- HTML
- CSS

## Arquitectura

La aplicación implementa una arquitectura MVC y utiliza los patrones
DAO y DTO.

## Funcionalidades

- Registrar incidentes.
- Consultar incidentes.
- Editar incidentes.
- Eliminar incidentes.
- Almacenar información en SQLite.

## Ejecución

Instalar las dependencias:

pip install -r requirements.txt

Ejecutar:

python app.py

Abrir en el navegador:

http://127.0.0.1:5000
